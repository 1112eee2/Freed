# SF_IDEAS: ไอเดียจาก Stockfish ที่ยืมมาใช้กับหมากฮอสไทยได้

ร่าง 2026-10-16 (งานวิจัยที่เจ้าของขอ) สถานะ: **backlog ยังไม่มีอะไรถูกวัด**
ทุกข้อเป็นสมมติฐานจนกว่าจะผ่าน screen → W1 (→ W2) ตามกติกาเดิม
ห้ามลอกค่าคงที่ของหมากรุกมาใช้ตรง ๆ ให้ปรับผ่าน SPRT เสมอ

แหล่งข้อมูล: release notes ของ Stockfish 16–19
([GitHub releases](https://github.com/official-stockfish/Stockfish/releases),
[SF 18](https://stockfishchess.org/blog/2026/stockfish-18/),
[SF 19](https://stockfishchess.org/blog/2026/stockfish-19/))
ส่วนเทคนิคการค้นหาที่เก่ากว่ามาจากความรู้ทั่วไปเรื่องประวัติ SF ซึ่งไม่ได้ตรวจทีละ commit
เลขรุ่นที่ระบุจึงเป็นช่วงโดยประมาณ

## สิ่งที่เรามีแล้ว (ไม่ต้องยืมซ้ำ)

TT, PVS, iterative deepening, quiescence ของตากินบังคับ, null move (ไม่ใช้เมื่อหมาก ≤ 6 ตัว),
LMR แบบง่าย (ลด 1–2), killer, history, ตาราง NNUE แบบ incremental + AVX2,
tablebase 3–6 ตัว, SPRT แบบ pentanomial พร้อม screen/W1/W2
และใน SEARCH_INT_01 ยังมี strict TT key, null-eval guard, log-LMR, history gravity/malus

## ประวัติที่ลองแล้ว (ห้ามรันซ้ำแบบเดิม ดู evidence ledger)

- aspiration window คงที่ 64 cp ช้าลงประมาณ 3.6% (2026-08-14)
- RFP_01 (reverse futility) INCONCLUSIVE ที่เพดาน 2,000 คู่
- ITER_PARTIAL_01 INCONCLUSIVE
- ปิด null move / ลด null แบบตื้น / ลดแรง 4 ชั้น: ไม่ผ่าน screen

### กลุ่ม 3: กระบวนการทดสอบ (fishtest)

| # | ไอเดีย | ปรับให้เรายังไง | คาดหวัง |
|---|---|---|---|
| T1 | **SPSA tuning** | หลังรวมฟีเจอร์แล้ว จูนค่าคงที่ทั้งชุด (margin, reduction, bonus ของ history) ทีเดียว ด้วยเกมเร็ว 1T แล้วยืนยันด้วย W1 ค่าตอนนี้ส่วนใหญ่เดามาหรือยืมมาจากหมากรุก | **สูง** (มักได้ Elo ฟรีหลังเพิ่มฟีเจอร์หลายตัว) |

## ลำดับที่เสนอ

1. **ระหว่าง Phase 01** (เขียนโค้ดเบา ๆ ได้ตอนที่ gate รัน แต่ต้องรอช่วงที่ไม่มี gate ถึงจะวัด):
   S1, S2, S3 แยกกันคนละ flag (ปิดเป็นค่าเริ่มต้น) แล้วรัน screen
   ถ้าตัวไหนผ่าน W1 ก่อนถึง R1 ก็เข้า RC-2 ได้ตามหลัก "ทุกอย่างที่ผ่านรวมเป็นค่าเริ่มต้น"
   แต่ไม่เลื่อน R1 เพื่อรอ
2. **หลัง RC-2 (V2.x)**: S4–S9 และ T1 (SPSA ทั้งชุด) รวมเป็น SEARCH_INT_02 แล้ววัดเทียบกับ RC-2
3. **NNUE รุ่นถัดไป**: N1 + N2 ก่อน (อยู่ในแผนอยู่แล้ว) แล้วตามด้วย N5 จากนั้น N3/N4 เป็นงานสถาปัตยกรรมของ V3
4. **ทำได้ตลอดเวลา**: T2, T3 เพื่อลดเวลาเครื่องต่อการตัดสินหนึ่งครั้ง
